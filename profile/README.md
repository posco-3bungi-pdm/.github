## Our approach

| 문제 정의 | 데이터 이해 | 모델 비교 | 보전 관점 해석 |
| :--- | :--- | :--- | :--- |
| 대상과 성공 기준을 먼저 | 시간·그룹·품질을 확인 | 기준선과 같은 조건으로 | 근거와 한계를 함께 |

설비 데이터를 활용해 이상 징후를 찾고, 점검·정비 판단에 도움이 되는 분석을 만듭니다. 현재는 프로젝트 착수 단계이며 세부 주제는 팀 합의로 확정합니다.

## How we work

**Issue → Branch → Pull request → CI → 3 reviews → Merge**

- 작업의 목적과 완료 기준을 Issue에 남깁니다.
- 자동 검사와 작성자 외 동료 3명 이상의 검토를 거쳐 결과를 합칩니다.
- 실험 조건·실행 방법·판단 근거를 함께 기록합니다.
- 원본 데이터는 공개 저장소에 올리지 않습니다.
